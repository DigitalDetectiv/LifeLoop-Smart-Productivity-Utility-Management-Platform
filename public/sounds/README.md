Drop your own royalty-free audio files here to enable the Rain and
Birdsong tracks in the Study Room's ambient player:

  public/sounds/rain.mp3
  public/sounds/birds.mp3

White noise, pink noise, and brown noise need no file at all - they're
generated live in the browser via the Web Audio API.

Until a file exists at one of the paths above, selecting that track in
the app shows a small note telling you which file to add, rather than
failing silently.
